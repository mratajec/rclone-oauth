Privacy Policy

Personal Rclone Sync is a private application intended solely for personal use by its owner.

Google User Data

The application uses Google OAuth to access the owner's Google Drive account for the purpose of synchronizing files using rclone.

Use of Data

Google user data is accessed only as necessary to perform file synchronization requested by the owner.

Data Sharing

Google user data is not sold, shared with third parties, or used for advertising.

Data Storage

OAuth authorization credentials and tokens are managed by rclone and stored on systems controlled by the application owner.

Third Parties

This application uses rclone to communicate with supported cloud storage services. The application is not offered to other users.
